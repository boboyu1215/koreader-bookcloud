# 书源说明

BookCloud 只查询你启用的来源，不提供统一的公共书库。初始配置包含 Project Gutenberg 的公开 OPDS 搜索入口，未附带第三方书源合集。

## 支持类型

| 类型 | 配置方式 | 说明 |
| --- | --- | --- |
| OPDS 搜索 | 填入包含 `{query}` 的 HTTPS 搜索 URL | 不是任意 OPDS 首页，需是可直接搜索的入口 |
| Gutendex | 填入包含 `{query}` 的搜索 URL | 示例：`https://gutendex.com/books/?search={query}` |
| 自定义目录 | 填写书籍 JSON 数组 | 参考 [catalog.json](../examples/catalog.json)，示例默认为停用且需替换地址 |
| Legado 静态文本 | 导入原始 JSON，或手动配置受支持的规则 | 只支持有限子集，不能承诺任意书源都可运行 |

远程来源需要使用可公开访问、具有有效证书的 HTTPS 地址。当前不允许私网 IP、非 443 端口、登录型来源或自定义请求头。这意味着即使书库由你自己搭建，也需要满足此连接方式；本机或局域网书库不能直接作为上游。

## 导入 Legado 规则

1. 在管理页面点击「导入 JSON」，选择你有权使用的规则文件。
2. 原始规则会去重并保留在待检测列表中；导入不等于已启用。
3. 展开「导入书源包」，使用「批量检测并启用通过的书源」。此操作会实际请求来源，通过的来源会自动启用。
4. 检测检查搜索、目录及首章。**样本通过不等于整本一定能下载**；下载时仍会逐章验证。
5. 在「我的书源」里可手动停用不想查询的来源。

规则包含 JavaScript、WebView、XPath、登录、验证码或付费章节时，当前不能支持。复杂选择器或模板也可能超出已实现子集。待检测列表会保留原因，不会因此删除原始规则。

支持的基本能力包括 CSS / class / id / tag 选择器、部分 JSONPath、基础替换、目录与正文分页。规则按数据解释，不执行脚本。

## 搜索与版本

来源只返回首批结果，界面翻页是对已返回结果的本地分页，不会继续向来源请求下一页。可缩小关键词以找到目标。

作品按规范化书名与作者启发式分组，来源、格式和版本会保留。全集与单册、别名或作者缺失可能导致分组不准确，请反馈具体例子。

## 下载与准备

普通来源由服务端获取文件后返回给阅读器。静态章节来源先合成为 EPUB，完成后再下载。单文件最多 50 MB；临时合成缓存最多保留四本，最长一小时，后续准备任务会清理过期缓存。服务器上的临时缓存过期不会删除已经下载到阅读器的文件。

来源授权、规则许可和内容的使用条件各自独立。请只连接你有权访问和使用的内容。
